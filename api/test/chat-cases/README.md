# 小白熊行程助手聊天测试用例

此目录保存部署前必须通过的聊天回归用例。用例分为两层：

1. **聊天响应**：验证用户话语被正确识别为写操作、只读查询或普通聊天。
2. **工具执行**：模拟用户确认工具后，执行生产代码中的同一套 handler，并断言行程数据确实正确新增、修改或删除。

当前覆盖：

- 出行物品新增、删除。
- 预定项修改。
- 花销新增、修改、删除。
- 指定日期行程、未完成预定、途经地点和花销总额查询。
- 普通陪聊和景点推荐。
- 问候语误触发删除的回归保护。
- 否定修改、上下文跟进、未知工具和重复提交保护。

首页生成与跨模块鲁棒性用例位于 `../trip-generation-robustness.test.js`，额外覆盖：

- 完整行程和信息不足的可编辑草案。
- 无意义文字、非旅行内容、未知国内外目的地短句。
- 日期倒序、跨年和混合省略年份。
- 生成后的主动修正、假设、缺失信息和风险提示。
- 自动修复失败时不得伪装成修复成功。
- 聊天撤销识别及防止撤销覆盖后续编辑。

可读用例及测试数据在 `cases.js`，自动执行器在 `chat-cases.test.js`。运行：

    npm test

测试仅操作内存中的行程副本，不访问 Azure，也不会修改线上数据。
